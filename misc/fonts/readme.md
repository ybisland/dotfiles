NerdFonts是把很多符号字符和常用字体(eg. FiraCode)打包在一起，形成的新字体

otf是ttf的新格式，能用otf先用otf。

每个字体都有很多style(eg. italic bold ..),字体文件一般有一个complete结尾的，这个文件包含了所有的style


字体存放位置：
Linux single user: ~/.local/share/fonts/
Linux for all users: /usr/share/fonts/ 
Windows: C:\Windows\Fonts


字体安装方法：
1. 在服务器上下载字体后，将字体文件放在用户字体目录或者系统字体目录下。(相当于设置后端)
2. 在本地机器上安装同样的字体，将iTerm2 / VS Code / Windows Terminal里的字体设置为安装的字体。(相当于设置前端)
